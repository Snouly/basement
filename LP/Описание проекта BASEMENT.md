# Описание проекта BASEMENT

BASEMENT - веб-приложение для управления устройствами умного дома через контроллер Aqara Home. Проект объединяет клиентскую часть для пользователя, серверное API и базу данных, позволяя просматривать устройства, отслеживать их состояние и выполнять базовые действия управления в едином интерфейсе.

## Актуальность темы

Технологии умного дома становятся всё более востребованными: пользователи устанавливают датчики, освещение, розетки и другие устройства, но часто сталкиваются с разрозненными приложениями, сложной навигацией и недостаточно наглядным отображением состояния оборудования.

Проект BASEMENT ориентирован на практическую задачу: сделать управление домашними устройствами проще, доступнее и удобнее для повседневного использования. Наличие серверной части и базы данных также позволяет развивать систему дальше: хранить сведения об устройствах, добавлять фильтрацию, расширять сценарии автоматизации и подключать новые функции.

## Целевая аудитория

Целевая аудитория проекта - пользователи систем умного дома, которым нужен простой способ контролировать состояние устройств Aqara и управлять ими через веб-интерфейс. Также проект может быть полезен начинающим разработчикам и студентам, изучающим создание full-stack-приложений, работу с REST API, базами данных и пользовательскими интерфейсами.

Потенциальными пользователями являются владельцы квартир и домов, использующие умные датчики, выключатели, лампы, розетки и другие устройства. Для них важны понятность интерфейса, быстрый доступ к списку устройств, отображение текущего состояния и возможность выполнять основные действия без лишней сложности.

## Предполагаемые функциональные возможности

- Просмотр списка устройств умного дома.
- Отображение текущего состояния устройств в реальном времени или с регулярным обновлением.
- Фильтрация устройств по помещению или расположению.
- Добавление нового устройства в систему.
- Включение и выключение устройства через интерфейс.
- Удаление устройства из списка.
- Взаимодействие фронтенда с сервером через API.
- Хранение данных об устройствах в базе данных.

В дальнейшем функциональность может быть расширена сценариями автоматизации, группировкой устройств по комнатам, журналом событий, авторизацией пользователей и более глубокой интеграцией с экосистемой Aqara Home.

## Используемые технологии

Предварительно проект строится как full-stack веб-приложение. Клиентская часть реализуется на React с использованием TypeScript и сборщика Vite. Серверная часть создаётся на Node.js и Express, а для работы с базой данных используется Prisma ORM. В качестве базы данных предполагается PostgreSQL. Обмен данными между клиентом и сервером выполняется через REST API.

- React и TypeScript - разработка пользовательского интерфейса.
- Vite - сборка и запуск фронтенд-приложения.
- Node.js и Express - серверная логика и API.
- Prisma ORM - работа с моделями данных и запросами к базе.
- PostgreSQL - хранение информации об устройствах.
- CSS Modules - оформление интерфейса.
- Aqara Home controller - предполагаемая основа для взаимодействия с устройствами умного дома.

## Ожидаемый результат

Ожидаемым результатом является работоспособное веб-приложение BASEMENT, позволяющее пользователю управлять устройствами умного дома через удобный и структурированный интерфейс. Пользователь сможет видеть список устройств, понимать их текущее состояние, добавлять новые устройства, включать или выключать их и удалять ненужные записи.

Проект должен продемонстрировать применение современных веб-технологий для решения практической задачи автоматизации дома. Итоговая система станет основой, которую можно развивать в сторону полноценной панели управления умным домом с расширенными сценариями, аналитикой и интеграцией с реальными устройствами.
